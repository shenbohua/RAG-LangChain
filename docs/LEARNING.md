# 辅助开发与辅助教学

用户决定目标并完成理解与练习；AI 辅助拆解、实现、解释、调试和验证。一次推进一个闭环，明确要求完整实现时直接交付。

1. 明确能力目标、前置知识、输入输出与成功条件。
2. 简述机制并完成最小实验；框架阶段对照底层实现。
3. 验证正常与关键失败路径，保存脱敏证据。
4. 解释关键代码与取舍，安排独立修改或排错。
5. 根据复述或实操验收理解，未收到证据标记待验收。
6. 更新学习记录、计划和遗留问题。

## 学习记录模板

每个实验创建 learning-log.md，记录：日期、阶段、目标、实际环境、依赖、命令、输入、预期、实际结果与证据、关键概念的个人解释、失败定位、独立练习结果、功能状态、学习状态、未解问题与下一步。不得包含密钥。
不编造学习者掌握程度；教学提示不阻塞已要求的实现。
